# Snowflake Basics

## Overview
This project demonstrates foundational Snowflake data warehousing skills, including database creation, table creation, data insertion, and querying data using SQL.

## Skills Demonstrated

### Database Management
- Created a database using Snowflake SQL.
- Managed database objects within the PUBLIC schema.

### Table Creation
- Designed and created relational tables.
- Defined appropriate data types for columns:
  - INTEGER
  - VARCHAR

### Data Loading
- Inserted multiple records into tables using SQL `INSERT` statements.
- Managed sample student data for testing and learning purposes.

### Data Querying
- Retrieved data using `SELECT` statements.
- Queried data from fully qualified object names:
  ```sql
  SELECT * FROM school.public.students;
